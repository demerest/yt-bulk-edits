1 Connect

One-click Google sign-in through auth-helper.ps1 on localhost:8787. The helper keeps the client secret and refreshes your access token automatically, so long batches never die mid-run.

Give the helper your OAuth client

Saved to auth-config.json next to the helper script. See SETUP.md for creating these (5 minutes, one time).

Fastest path, no Google Cloud project needed: open Google OAuth Playground ↗, authorize the .../auth/youtube scope, click Exchange authorization code for tokens, and paste the access token here.

Access tokens expire after about an hour. If a long batch stops with an auth error, paste a fresh token and re-run — already-applied edits stay applied and remain restorable.

Uses your own OAuth client and exchanges the code in this page (PKCE, no helper process). You get a refresh token, so the session survives reloads.
